# Project Leonida V2

Rewriting [Leonida](https://github.com/ItsNotRexed/Leonida) in Rust: GTA VI (Xbox Series, 1.0.2.1) on PC, built
from your own copy. Pure Rust, no C or C++.

**Status:** planning. Nothing runs yet.

No game files are in this repo, and none ever will be.
